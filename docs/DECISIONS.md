# Production decisions

- One Short only, not a long documentary or series production.
- Navy / warm ivory / acid lime / coral original financial-documentary palette.
- Narrative arc: apparent lender → issuing bank → authorization network → toll
  road analogy → revenue shares → residual risk → connection economics.
- No fabricated financial numbers and no quantitative fee chart. Fee nodes say
  not to scale because actual prices depend on contract, geography and product.
- Original diagrams distinguish authorization messages from an actual transfer
  of borrowed funds. Settlement exposure is explicitly retained in the story.
- Local neural voice avoids API costs and external transmission of the script.
- No music rather than introducing an unverified music license or masking speech.
- Twelve short scenes and sentence captions provide an update every 3–5 seconds.
- Research verification and technical validation are separate. Rendering a valid
  MP4 does not make blocked primary-source research complete.
- No changes to the published cloud environment configuration are requested.
  Project dependencies are isolated in the authorized checkout instead.
